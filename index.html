LAPORAN INVENTORY BARANG

Template Excel & Cadangan Data

Format profesional

File Excel (.xlsx) memakai judul berwarna, header biru, filter, baris judul dibekukan, lebar kolom yang disesuaikan, dan format Rupiah. Gunakan template kosong untuk mengisi data secara massal. Impor barang akan menambah atau memperbarui data berdasarkan Kode Barang; transaksi masuk/keluar yang diimpor juga memperbarui stok.

📦 Template Gudang

Kolom master barang, stok, satuan, harga dan lokasi.

📥 Template Barang Masuk

Tanggal, kode barang, jumlah, pemasok, dokumen, keterangan.

📤 Template Barang Keluar

Tanggal, kode barang, jumlah, penerima, dokumen, keterangan.

🛒 Template Penjualan

Nomor nota, tanggal, kode barang, jumlah, harga dan pelanggan.

Impor Data dari Excel / CSV

Buat cadangan terlebih dahulu sebelum impor. Baris yang tidak valid akan dilewati dan ditampilkan di pesan hasil.

Petunjuk Format

  • Kolom wajib Gudang: Kode Barang, Nama Barang, Kategori, Stok, Harga Satuan. Kode barang harus unik.
  • Barang Masuk/Keluar memakai Kode Barang yang sudah terdaftar. Jumlah wajib bilangan bulat positif.
  • Impor barang masuk menambah stok; impor barang keluar mengurangi stok dan ditolak jika stok tidak cukup.
  • Impor transaksi penjualan mengurangi stok seperti kasir biasa.
  • Impor master gudang akan memperbarui data barang berkode sama. Perubahan stok langsung pada master tidak membuat riwayat pergerakan.
  • Data disimpan di localStorage browser. Data tidak otomatis tersinkronisasi antarperangkat.
